# Shared Agent Instructions

This repository stores shared agent instructions and reusable skills for use across multiple projects.

## Skills

Skills live under `.agents/skills/<name>/SKILL.md`.

- Skills manifest: `.agents/skills/manifest.md`
- Skill template: `.agents/skills/_template/SKILL.md`

## Instruction Index

- Primary `.agents` entrypoint: `.agents/README.md`
- Shared operating guidance: `.agents/instructions.md`
- Skills manifest: `.agents/skills/manifest.md`
